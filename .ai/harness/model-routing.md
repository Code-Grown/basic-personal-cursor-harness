# Model routing (generic)

| Tarea | Preferencia |
|---|---|
| Typo, un archivo, explore, subagente rutinario | Composer o heredar (omitir `model`) |
| Arquitectura, seguridad, bug cruzado difícil | Modelo fuerte del chat (p. ej. Grok) o el que pida el usuario |
| Pedido explícito | Respetar siempre |

No forzar el modelo caro en cada subtarea. El selector del chat manda.
