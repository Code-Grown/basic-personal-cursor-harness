# Read budget (generic)

Be effective without over-reading.

## Default order
1. Compact workspace map / discovery result.
2. **One** active skill or stack guide.
3. Concrete file only when path is known or grep narrowed it.
4. Full constitution / multi-agent packs: on-demand only.

## Limits
- Do not re-read harness docs already in the thread.
- No speculative searches when the path is known.
- Prefer indexes and short diffs over full rewrites.
- Mentor / multi-agent modes: only when asked or clearly needed.

## Smell of over-reading
Reloading the same indexes every turn · loading ultra OM + 4 agents for a UI typo · dumping long docs into alwaysApply rules.
